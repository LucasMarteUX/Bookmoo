# Prompts para gerar as capas e os banners no ChatGPT (gpt-image)
Gere cada capa **no ChatGPT com geração de imagens**, **anexando a capa de referência indicada** (os livros já cadastrados no Bookmoo servem de guia de estilo). Dá para fazer **uma capa por vez** (mais confiável para o título) ou **4 numa só imagem** (mais barato; veja a seção 'Grade de 4').
## Como usar
1. Abra o ChatGPT e anexe a imagem de referência sugerida (baixe a capa no Bookmoo ou pegue de `content/epubs/<pasta>/cover-ai.jpg`).
2. Cole o **prompt base** abaixo e depois o **prompt do livro**.
3. Formato: retrato 2:3 (1024×1536). Peça sempre: *'não escreva nenhum outro texto além do título e do autor'*.
4. **Confira a grafia** do título e do autor na imagem (letra por letra). Se errar, peça só para corrigir o texto.
5. Salve como `<n>.jpg` (n = número entre parênteses) e me envie a pasta. Eu redimensiono para 600×900, crio a miniatura, confiro de novo e gravo no banco.
## Prompt base (cole antes de cada prompt de livro)
```
Use the attached cover only as a STYLE reference (same level of finish, lettering personality and framing quality), but create a completely NEW, original cover for a different book. Original artwork for a public-domain classic, wholesome, suitable for all ages. It must NOT be based on any film, TV series, game, brand, trademark, modern edition or real person. Portrait book cover, 2:3 ratio (1024x1536). The title and the author are drawn as part of the artwork in custom hand-made lettering, large and perfectly legible, and the author's name is smaller below it. Spell both texts EXACTLY as given, letter by letter, and include NO other text of any kind. No logos, no watermark, no barcode, no store borders. CLEAN FINISH: smooth, polished, professional commercial book-cover rendering with crisp edges and smooth gradients; absolutely no canvas texture, no craquelure, no film grain, no noise, no dirty or distressed effects. Not washed-out, not blurry, high contrast.
```
